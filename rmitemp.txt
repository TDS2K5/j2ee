Server.java
It should contain 3 main parts.
1. Constructor( Generate it using insertCode)
2. Implement all the methods of Method.java
3. Write Public Static Void Main(String args[])
public class Server extends UnicastRemoteObject implements Methods {
//step 1: constructor
public Server() throws RemoteException {}
//step 2: method implementation
//step 3: main method
public static void main(String[] args) {
try {
LocateRegistry.createRegistry(1099);
Server s = new Server();
Naming.rebind("rmi://localhost:1099/ServerObject", s);
System.out.println("RMI Registry started on port 1099...");
} catch (Exception e) {
System.err.println(e);
}
}
}
